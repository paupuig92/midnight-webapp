# Bass in the Park 2026

Horari en directe del festival (24.10.2026 · Montmeló): qui punxa ara, què ve a continuació, preferits amb avís i graella amb la línia de l'hora actual.

- `index.html` — l'app (versió per a l'artifact de Claude).
- `img/` — cartell i logos dels escenaris.
- `build_web.py` — genera `docs/`, la versió que publica GitHub Pages (HTML complet, icona, funciona sense connexió).

Per actualitzar el web: edita `index.html`, executa `python3 build_web.py` i fes commit + push.
